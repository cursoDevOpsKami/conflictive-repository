## Separate directories structure 

I organized the project into separate directories for the frontend, backend, and Nginx configuration. This separation ensures clarity, maintainability, and allows each component to be managed independently. The frontend handles user interaction, the backend processes data, and Nginx acts as the reverse proxy connecting them all.
